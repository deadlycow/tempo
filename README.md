# ⏱️ TEMPO

### Modern Time Reporting & Workforce Management Platform

<p align="center">
  Built with React, TypeScript, ASP.NET Core & SQL Server
</p>

<br/>

<img src="https://img.shields.io/badge/React-19-blue?style=for-the-badge&logo=react" />
<img src="https://img.shields.io/badge/TypeScript-5-blue?style=for-the-badge&logo=typescript" />
<img src="https://img.shields.io/badge/.NET-9-purple?style=for-the-badge&logo=dotnet" />
<img src="https://img.shields.io/badge/TailwindCSS-4-38B2AC?style=for-the-badge&logo=tailwind-css" />
<img src="https://img.shields.io/badge/License-MIT-green?style=for-the-badge" />

<br/>
<br/>

TEMPO is a modern workforce and time reporting platform designed for teams and project-driven organizations.

The system allows employees to report weekly work hours, track projects, monitor approval status, and review historical submissions while giving team leaders powerful tools to manage and verify reports.

# 🏗️ Architecture

TEMPO follows a layered architecture structure inspired by Domain-Driven Design principles.

```txt
/client
  /components
  /pages
  /services
  /contexts
  /hooks

/server
  /Controllers
  /Services
  /Repositories
  /Entities
  /DTOs
  /Contexts
```

# ⚡ Getting Started

## Clone Repository

```bash
git clone https://github.com/yourusername/tempo.git
```

---

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

Frontend runs on:

```txt
http://localhost:8080
```
